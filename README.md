# Wallhaven 下载器
纯靠deepseek辅助编程（我俩真是太厉害了）
一款Wallhaven 壁纸批量下载工具

## ✨ 功能特性
- 支持按分类筛选（动漫、风景、人物等）
- 支持分辨率筛选
- 批量下载，一键保存
- 图形化界面，简单易用
